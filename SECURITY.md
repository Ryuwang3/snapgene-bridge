# Security and data handling

The bridge is designed for unpublished local sequences. It has no network
client in the MVP and does not upload input files. Optional scientific
libraries run in the same local process.

When reporting a bug, replace private sequences and annotations with a small
synthetic fixture. Do not commit `.dna` files, sequencing traces, credentials,
or vendor order sheets.

Report a suspected code or dependency vulnerability privately to the
repository maintainers before opening a public issue.
